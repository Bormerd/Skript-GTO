# Скрипт сопоставления участников с колледжами

Скрипт предназначен для автоматического определения колледжа участника на основании данных из протоколов, расположенных в отдельных папках колледжей.

Основной алгоритм:

1. Поиск основного Excel-файла.
2. Получение списка участников.
3. Сканирование директории `Колледжи`.
4. Обработка протоколов.
5. Сопоставление участников по УИН и ФИО.
6. Формирование результирующего Excel-файла.
7. Формирование файла диагностики.

---

- Python 3.10+

## Основной Excel-файл

Скрипт автоматически находит основной Excel-файл по наличию листов:

| Параметр | Обязательность | Тип |
|----------|----------------|-----|
| `Золото` | Обязательно | Лист Excel |
| `Серебро` | Обязательно | Лист Excel |
| `Бронза` | Обязательно | Лист Excel |

Имя основного файла указывать в коде не требуется.

На листах должны присутствовать:

| Параметр | Обязательность | Тип |
|----------|----------------|-----|
| `ФИО` | Обязательно | Строка |
| `УИН` | Обязательно | Строка |

Дополнительные поля (`ЦТ`, `Ступень`, `Знак`, `Номер удостоверения` и т. д.) сохраняются без изменений.

## Директория `Колледжи`

Все протоколы должны находиться внутри директории:

```text
Колледжи/
```

Каждый колледж должен иметь отдельную директорию.

Название директории используется как название колледжа.

Например:

```text
Колледжи/
└── Костромской энергетический техникум/
    └── protocol.xlsx
```

Результат сопоставления:

```text
Костромской энергетический техникум
```

Скрипт рекурсивно ищет все файлы:

```text
*.xlsx
```

внутри директории `Колледжи`.

## Алгоритм сопоставления

При обработке протоколов формируются индексы:

```text
УИН → колледж
ФИО → записи протоколов
```

Приоритет поиска:

```text
УИН → ФИО → ручная проверка
```

### Сопоставление по УИН

УИН является основным идентификатором.

Перед сравнением удаляются:

- пробелы;
- дефисы;
- переносы строк;
- окончание `.0`, появившееся при обработке Excel.

Например:

```text
1234-5678-9012
1234 5678 9012
123456789012
```

приводятся к сопоставимому виду.

Если УИН найден однозначно, участнику присваивается соответствующий колледж.

---

### Сопоставление по ФИО

Если УИН не найден, выполняется поиск по ФИО.

При нормализации:

- удаляются лишние пробелы;
- текст переводится в нижний регистр;
- `ё` заменяется на `е`;
- удаляется пунктуация.

Если ФИО найдено однозначно, участнику присваивается соответствующий колледж.

Если найдено несколько вариантов, автоматически колледж не назначается.

---

## Конфликты

Если один УИН найден в протоколах нескольких колледжей, создаётся конфликт.

Пример:

```text
УИН: 123456789012

КЭТ
КМТ
```

Скрипт не выбирает случайный колледж. Конфликт записывается в файл диагностики.

---

## Результаты

После обработки исходный файл не изменяется.

Создаются два файла:

```text
<имя_основного_файла>_с_колледжами.xlsx
<имя_основного_файла>_ДИАГНОСТИКА.xlsx
```

Например:

```text
г. Кострома Политех_с_колледжами.xlsx
г. Кострома Политех_ДИАГНОСТИКА.xlsx
```

В результирующем файле сохраняются листы:

```text
Золото
Серебро
Бронза
```

и заполняется колонка:

```text
Колледж
```

## Диагностика

Файл диагностики содержит информацию о результатах сопоставления.

Возможные статусы:

| Статус | Описание |
|--------|----------|
| `Найден по УИН` | Участник найден по УИН |
| `Найден по ФИО` | Участник найден по ФИО |
| `Не найден` | Участник отсутствует в протоколах |
| `Конфликт УИН` | УИН найден у нескольких колледжей |
| `Неоднозначное ФИО` | Найдено несколько совпадений |
| `Ошибка чтения файла` | Ошибка обработки протокола |

---

## Нечёткие совпадения

Нечёткое совпадение ФИО не является подтверждением личности.

Такие совпадения не используются для автоматического назначения колледжа и предназначены только для ручной проверки.
